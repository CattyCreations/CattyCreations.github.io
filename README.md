# CattyCreationsUI

Website for Catty Creations.

## GitHub Pages

The site is deployed from the `main` branch using GitHub Actions:

1. In the repository settings, open **Pages** and set the source to **GitHub Actions**.
2. Push a commit to `main`, or run the **Deploy to GitHub Pages** workflow manually.

The published site is available at <https://cattycreations.github.io/CattyCreationsUI/>.
